# Betalens 研究员完整课程

适合对象：会使用 Excel、能够提出研究问题，但刚开始接触 Python 的研究员。

课程目标：能够独立提出研究假设，核验数据，运行和修改因子，复核持仓与收益，比较实验，写出别人能够复现的研究报告。课程不以回测盈利作为毕业条件。

这是一套可自学的课程正文、实验、参考答案和项目模板。前一份《研究员入门》保留作速查手册；原来的 `first_factor.py` 归入本课程第 04 课。

## 使用方式

建议每周 3 课，共 8 周。每课约 60—90 分钟，另留时间准备真实数据和完成毕业项目；时间仅是学习安排估计。每次按“读原理 → 手算例子 → 操作 → 做练习 → 对照验收”的顺序学习。

不用第一天就把数据库搭完。第 01—04 课可先离线学习；若第 05—07 课环境或数据暂时未就绪，可先做其余课的离线部分，数据验收后再补真实回测。真实结果未知处必须写“待验证”。

所有命令默认在 Windows PowerShell、仓库根目录 `D:\git_clone\betalens` 执行。Markdown 里的 Python 代码要放入 `.py` 文件或 Python 编辑器运行，不能直接当 PowerShell 命令粘贴。

## 可立即运行的实验

```powershell
Set-Location D:\git_clone\betalens
python docs/learning/labs.py --list
python docs/learning/labs.py 02
python docs/learning/first_factor.py
```

`labs.py` 中课次为 02、03、08、09、10、11、13、15、16、21、22、23。共 12 个新增实验，加上第 04 课原练习，共 13 个离线实验。

```powershell
# 检查整套新增离线实验，不访问数据库、不写文件。
python docs/learning/labs.py all
```

| 实验类型 | 对应课次 | 边界 |
| --- | --- | --- |
| pandas/NumPy 教学演算 | 02、03、08、09、21、22、23 | 使用虚构数据，部分展示研究原理，不能冒充实际项目绩效 |
| Betalens 真实分组与预处理 | 04、10、11 | 使用真实 API，输入是虚构数据 |
| Betalens 真实回测引擎 | 13 | 内存预载价格、关闭交易状态查库，没有真实成交数据 |
| Betalens 真实指标与 IC | 15、16 | 指标使用源码纯函数，统计样本是虚构的 |

第 15 课通过直接加载 `metrics.py` 运行纯函数，避免触发完整报告包的额外依赖。正式研究应安装完整依赖后使用常规 import。

实验内的 `assert` 是固定教学输入的核对，改数据后预期答案也会改变。如果出现 AssertionError，先比较手算结果，不能为了“变绿”直接删掉核对。

## 本次核验边界

课程基于本地仓库 2026-09-04 的代码；后续版本请重新核对默认值。新增离线实验已逐项运行通过。真实数据库查询、导入、Dashboard 回测、完整教学因子的市场回测、参数挖掘和 Bootstrap 正式检验均未执行。课程内这些部分提供操作步骤和验收要求，不预填成功结果。

当前环境可运行离线实验，但完整 Analyst 导入曾提示缺少 `prettytable`，需按第 05 课安装项目依赖。课程编写没有修改核心库、已有因子、数据库或 Python 环境。

## 你什么时候算学会了？

当你能不看教程解释一次运行的假设、样本、时间戳、公式、权重、成交、收益和限制，并能让另一位同事照你的记录重跑，课程目标就达到了。收益为负但方法严谨、原因清楚的研究，同样可以合格。
