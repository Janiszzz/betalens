## 第 09 课：把研究公式写成算子

**目标与原理。** 算子是“输入表格，输出表格”的函数。研究员主要编写公式，通用管线负责取数、分组、回测和报告。函数参数名字要与 YAML 中 `factor_spec.inputs` 对应。

```python
def compute_momentum(close_wide, window):
    return close_wide / close_wide.shift(window) - 1
```

这里 `window` 是沿时间轴回看多少行。如果输入已对齐标准日频交易日，20 行就表示 20 个交易日。缺交易日会改变回看含义，不能把任意散乱价格表直接套入公式。

**例子。** A 的价格为 10、11、12，窗口为 2 时第三个值为 `12/10-1=20%`。最前面两行历史不够，输出为空。不能通过把这些空值填成未来算出的分数解决。

**操作。**

```powershell
python docs/learning/labs.py 09
```

观察 A 上涨、B 下跌，分数为何一正一负。再把窗口从 2 改为 1，对比首个有效日期与因子波动。

**练习。** 写出三行移动平均：`close_wide.rolling(3, min_periods=3).mean()`。再写价格相对均线的偏离：`close_wide / moving_average - 1`。说明它与过去三行涨幅有什么不同。

**验收。** 输入和输出日期、代码能对齐；能手算至少一个值；知道公式回看长度与 `warmup_days` 的自然日单位不同。多层滚动公式的累计历史需求可能超过任意一个单独窗口。

## 第 10 课：去极值、标准化与中性化

**目标与原理。** 去极值限制极端值影响；标准化改变分数尺度；中性化剔除可由控制变量解释的部分。三者回答不同问题。

当前 MAD 去极值实现使用 `中位数 ± n×MAD`，MAD 是偏离中位数的绝对值的中位数。它没有在这一步乘额外的一致性缩放常数，复算时按源码口径。

**例子。** 分数 `[1,2,3,4,100]`，中位数为 3，绝对偏差中位数为 1；n=3 时上界为 6，所以 100 被截到 6。zscore 再用 `(x-均值)/标准差` 变换；在有变异的样本中，这种线性标准化本身不改变排序。

行业中性化可写成 `分数 = 截距 + 行业解释部分 + 残差`。若行业甲整体分数低、行业乙整体分数高，拿残差排序会更关注各自行业内部的相对强弱。

**操作。**

```powershell
python docs/learning/labs.py 10
```

本例用十二只虚构股票、两个行业，调用真实 `neutralize_factor`。检查 `skipped=False`，并观察残差在每个行业中的均值接近零。很小的 `1e-17` 是浮点误差尺度，不必把它解释为实质暴露。

**练习。** 把样本压缩到四只，查看是否跳过中性化。当前实现要求有效样本至少达到“控制变量列数 + 5”，样本不足会返回原分数并标记 skipped。

**验收。** 能区分“开启了配置”和“实际执行成功”；能说明因子残差中性不保证最终分组选出的组合行业权重完全中性。通用管线在行业或市值中性化开关开启时进入这一整段预处理，关掉两者不能仍声称全部预处理已完成。

## 第 11 课：分组边界与明确的权重规则

**目标与原理。** 分组是将连续分数转换为类别。权重是将类别转换为仓位。分组数、权重侧别、组间分配、组内分配都属于研究定义。

**例子。** `[0,0,0,0,1,1]` 分三组：`equal_count` 可把同为 0 的股票按代码顺序拆开，得到三组，每组两只；`value` 保证同分值不跨组，实际可能只得到两组。后者的最高标签可能不是你预想的 2。

**操作。**

```powershell
python docs/learning/labs.py 11
```

比较两种标签，查看 `freeplay` 下 `long: ["max"]`、`short: []` 如何只持有最高组。程序还故意请求将六只股票分成十个等额组，捕获并显示错误，让你学习如何读报错。

注意低层函数参数名是 `long/short`，完整 YAML 中用 `long_groups/short_groups`，配置转换层负责映射。

**当前项目的明确用法。** 经典多空固定高组多、低组空；反向组合用 `freeplay` 明确 `long_groups: [min]` 与 `short_groups: [max]`。不能仅靠 `direction` 字段推定已反转。`value` 分组下用 max/min，避免组数变化使数字标签失效。

**练习。** 在六只分数互异的股票上分别构造高组单多、低组单多、经典多空。计算股票权重和、绝对权重和与现金权重，解释三种研究问题的差别。

**验收。** 能说明“十组”不是“十只股票”；不会把多空差收益与普通单多收益在未注明敞口的情况下直接比较。

## 第 12 课：用 YAML 和 Dashboard 跑完整实验

**目标与原理。** `meta` 写研究说明，`factor_spec` 定义输入与公式，`weight` 定义组合，`run` 定义日期、调仓、资金和输出。完整 YAML 是本次实验的参数来源，类级文件不能替代缺失的完整因子配置。

**操作一：界面。** 运行 `./dashboard/run.bat`，访问 `http://127.0.0.1:5173`。选 ALPHA101 截面版，选已核验数据覆盖的短区间，先保持其他规则固定。提交后跟踪日志；后端默认串行跑回测，排队不是必然卡死。

**操作二：命令行。** 在 ALPHA101 同目录复制完整 YAML，命名为 `factor_ALPHA101_learning.yaml`，修改副本中的日期、组数和 `output_dir`，再运行：

```powershell
python betalens-factor/alpha101/ALPHA101/factor_ALPHA101.py --config betalens-factor/alpha101/ALPHA101/factor_ALPHA101_learning.yaml
```

修改片段示意，不能用它覆盖整个 YAML：

```yaml
run:
  start_date: '2024-01-01'
  end_date: '2024-03-31'
  rebal_freq: W
  grouping_mode: equal_count
  n_quantiles: 5
  initial_amount: 100000000
  benchmark_code: 000906.SH
  include_profiling: true
  dump_excel: true
  warmup_days: null
  output_dir: outputs/runs/lesson12_01
```

日期仅为示例，要使用库内覆盖的日期。相对输出路径以 YAML 所在目录为基准。第二次实验换输出目录，防止同名文件覆盖。

**例子。** `n_quantiles` 从 5 改到 10，会缩小最高组范围，改变集中度和取整影响，不保证收益提高。

**练习。** 找到本次配置、日志、报告、dump 和 profiling；选一个调仓时点，找出对应实际持仓。Dashboard 的 `run_config.yaml` 比页面里你记得填了什么更可靠。

**验收。** 能说出实际区间、股票池、价格指标和有效样本数；运行成功但结果为空不能过关。CLI 通用管线主要生成 Excel 和静态图，不应假设自动有交互 HTML。

**阶段作业。** 保存一份真实运行档案。如果尚无数据，提交配置审阅与依赖清单，并明确标注“待真实运行”，暂不进入真实结果解读。
