## 第 01 课：把想法变成可检验的假设

**目标与原理。** “动量有效吗”过于笼统。研究需要明确对象、时间、变量和比较方式。一个可执行的版本是：“在某历史股票池中，以过去 20 个交易日涨幅排序，按周形成高低分组合，比较下一持有期的表现。”先规定规则，再观察结果。

在 Betalens 中，这句话会拆成 `index_code`、`compute_kwargs.window`、`rebal_freq`、`weight` 和起止日期。变量名看起来技术化，本质都是研究设计选择。

**例子。** 甲公司过去涨了 20%，乙公司过去跌了 10%，只能说明历史强弱不同。你要检验的是之后的相对表现，不能用过去的涨幅直接证明预测能力。还需要考虑行业、规模、样本成分变化等解释。

**操作。** 打开[实验记录模板](templates/实验记录模板.md)，先用文字填写假设、股票池、公式、信号可知时间、成交假设和评价指标。不确定的数据日期写“待核验”，先不要填写任何“预期收益目标”。

**练习。** 把“高股息股票更好”改写成一条能交给程序执行的研究问题。至少说明股息率定义、股票池、调仓频率、比较对象和可得时间。

**验收。** 同事无需问“更好是什么意思”“研究谁”“什么时候买”，就能据你的文字列出参数。能解释因子值、因子组合、因子收益三者区别。

**常见错误。** 先挑最好看的历史曲线，再编写支持它的研究假设。这种做法把探索当成验证，后面必须补独立验证区间。

## 第 02 课：只学研究马上用得上的 Python

**目标与原理。** 暂时掌握变量、列表、字典、函数和表格。`close = 10` 是给一个值命名；`[10, 11]` 是列表；`{"window": 20}` 是参数字典；`print(close)` 是调用函数显示结果。`import pandas as pd` 是加载表格工具并给它一个短名字。

`Series` 类似带行标签的一列数据，`DataFrame` 类似 Excel 工作表。表格的 index 是行标签，不一定是从 1 开始的行号。

**例子。** 长表的每一行记录一个“日期—股票”；宽表以日期为行、股票为列。两只股票、两天价格，在长表里有四行，在宽表里是 2×2。`pivot` 是改变摆放方式，不改变价格本身。若同一日期同一股票有两条冲突价格，不能不加判断就透视。

**操作。**

```powershell
python docs/learning/labs.py 02
```

然后在 `labs.py` 中找到 `lab02`，对应阅读：`pd.DataFrame` 建表，`pd.to_datetime` 转日期，`.loc[...]` 筛选，`.pivot(...)` 转宽表。`long["code"] == "A"` 产生逐行的真假判断，外层 `.loc` 只保留真值行。

**练习。** 复制实验到自己的练习文件，添加第三只股票 C，两天价格分别为 30、33。筛选第二天所有股票，只输出代码和收盘价。不要改原始课程基准文件。

**验收。** 能解释为何加入 C 后长表有六行、宽表有三列，能读取第二天 C 的值 33。能分清字符串 `"10"` 与数值 `10`。

## 第 03 课：收益、复利和时间标签

**目标与原理。** 一期简单收益 `r = P_end / P_start - 1`。多期累计收益是 `(1+r1)(1+r2)…-1`。日收益在日期 t 上通常表示从 t-1 到 t 的已经发生收益，而因子评价需要的是形成信号之后的收益。

**例子。** 价格 100 → 110 → 99，两期收益是 +10%、-10%，累计 -1%。平均日收益为零不等于累计收益为零。

`shift(1)` 把此前一行移到当前行；`shift(-1)` 把下一行移到当前行。后者可用于构造未来收益标签，但不能作为当时已知的打分输入。

**操作。**

```powershell
python docs/learning/labs.py 03
```

观察“已发生收益”和“下一期收益标签”两列。首行没有前期价格，已发生收益为 NaN；末行没有下一期价格，未来标签为 NaN。这些空值有含义，不能机械地补零。

**练习。** 手算 100 → 90 → 99 的每期和累计收益。画四个时点：数据公开、信号形成、实际成交、持有期结束。若信号用当日收盘价且下日收盘才成交，评价收益的起点应使用哪一个价格？

**验收。** 能得出累计 -1%；能说明“信号日后的收益”和“实际可获得的持有收益”未必相同。知道 `pd.bdate_range` 只排除周末，不能代替交易所节假日日历。

## 第 04 课：从因子分数到组合收益

**目标与原理。** 本课使用 ALPHA101 的简单公式和项目真实分组函数，跑完整条“打分 → 排序 → 分组 → 权重 → 单期收益”链条。

```text
score = (close - open) / (high - low + 0.001)
```

**例子。** 六只股票的分数从 A 到 F 递增，三组分别是 AB、CD、EF。经典多空做多 EF、做空 AB，各侧等权。若未来收益为 A=-2%、B=-1%、E=3%、F=4%，组合收益是 5%。这些是人为构造的演算数据。

**操作。**

```powershell
python docs/learning/first_factor.py
```

阅读 `single_characteristic` 调用：输入是含日期、代码和分数的表；输出新增 `score_label`。阅读 `get_single_factor_weight`：输入标签，输出以日期为行、代码为列的权重表。最后的乘法只是教学收益演算，还没有执行完整回测引擎。

**练习。** 手算四只持仓的收益贡献。解释负权重乘负收益为何是正贡献。将高分组未来收益改为 -3%、-4%，保持低分组不变，重算结果。

**验收。** 原输入得到 5%，修改后得到 -2%。能解释现金列为何在这类净敞口为零的多空记账里为 1，而股票总绝对敞口为 2，不能解读为“100% 现金、没有股票”。
