## 第 13 课：真实回测引擎如何把仓位变成净值

**目标与原理。** 目标权重不是持股数量。引擎用当时总资产和成交价将目标转为股数，再按每手股数截断；持股价格变化形成损益，损益又改变下一期总资产。

```text
目标股数 = 目标权重 × 当前净资产 / 成交价格
实际股数 = trunc(目标股数 / 每手股数) × 每手股数
```

`trunc` 向零截断；负股数是空头，不能直接用始终向下取整替代。

**例子。** 10 万元按 100 元买入 1000 股，价格依次变成 110、90、120、130，净值是 1、1.1、0.9、1.2、1.3。若每次目标仍为全仓，持股仍为 1000 股，重新计算目标不等于真的发生了新交易。

**操作。**

```powershell
python docs/learning/labs.py 13
```

这是实际调用 `BacktestBase`，通过 `preloaded_cost_price` 和 `preloaded_close_price` 提供内存价格，并关闭外部交易状态查询。它能展示引擎算术，但不能验证市场数据质量或现实可成交性。

**练习。** 手算 1 万元预算、30 元股价、100 股一手时的实际股数与剩余现金。把真实运行的 `weight` 与 `actual_weight` 并排，对比五只股票的差异。

**验收。** 教学例净值与手算一致，持股数始终 1000，交易日志只有首次买入。能解释为什么小资金、较贵股票、过细分组可能产生大量现金。

## 第 14 课：执行口径比一条净值曲线更重要

**目标与原理。** 回测至少有数据时点、信号时点、请求交易时点、实际匹配价格时点和持有期结束时点。任何一个错位，都可能让实验获得本来无法获得的收益。

**当前源码路径。** 通用截面管线先产生周期调仓日，选前一交易日为信号日；权重沿用输入行情的时间戳，加 10 分钟后提交给回测。引擎在后续区间内寻找价格。默认日线收盘数据在 15:00 时，通常会匹配下一交易日收盘；若原始数据错标为零点，实际语义会改变。

直接构造 `BacktestBase` 的默认 `time_tolerance=24` 小时，当前通用管线调用时传入 `24*11`。这两个路径默认值不同，必须查本次实际运行。

**操作。** 从真实 dump 找 `actual_datetime`、`cost_price`、`actual_weight` 与 `rebalance_log`，抽查至少三个信号：普通交易周、跨假期、缺价或停牌期。若没有第三类样本，写明未覆盖，不能声称已验证。

**例子。** 用周四收盘打分，周五收盘才成交，那么周四到周五的上涨不能算作已持仓收益。指数成分、行业分类和财报也需要按其可知时点解释。

**实现限制。** 当前 `ftc/ptc` 仅见保存和导出，未见参与净值扣费。`to_cash` 是停牌目标权重规则，不是即时卖出的市场保证。价格是否复权、分红如何处理、融资融券和涨跌停是否覆盖，都需要实际核验；设置中没有明示实现的条件不能自行补充到研究结论里。

**练习与验收。** 用自己的语言写出一次完整信号到收益的时间线；列明费用、滑点、状态处理和价格调整口径。若评估交易成本，可另列“按明确换手定义估算的成本情景”，不能把估算列冒充引擎已经扣费的净值。

## 第 15 课：报告指标如何算，如何解释

**目标与原理。** 累计收益看起终点，回撤看路径，波动看变化幅度，夏普比较平均超额收益与波动。不同指标共同描述实验，没有一个指标能代替数据和执行审计。

**例子。** 净值 1 → 1.2 → 0.9 → 1.1，累计收益 10%，最大回撤幅度为 `(1.2-0.9)/1.2=25%`。本项目 `max_drawdown` 返回正的幅度 0.25；图表画成 -25% 时是符号表达差异。

**操作。**

```powershell
python docs/learning/labs.py 15
```

实验还展示短样本年化为何可能极端。当前 `annualized_return` 用 `len(nav)` 作指数分母；有人用收益区间数 `len(nav)-1`，两者会不同。本课程按当前源码解释，不暗中改成另一公式。夏普纯函数默认年化因子 252、无风险利率 0；周频收益不能不加说明地直接套日频年化因子。

完整依赖和回测对象准备好后，常规报告入口：

```python
from betalens.analyst import Analyst

# bt 是已经完成的真实回测对象。
analyst = Analyst.from_backtest(bt, name="MyResearch")
analyst.report(to_excel="report.xlsx", to_html="report.html", show_plots=False)
```

没有 bt 时不能直接运行这段片段。若从 dump 重读，可用 `Analyst.from_excel("具体dump路径.xlsx")`，它读取的是回测 dump，不是任意普通 Excel。

**练习。** 对自己的报告写三段话：发生了什么、哪些证据支持、什么还没验证。不要只抄年化收益率。检查完整区间和各年表现是否一致，短期回测只用于验证流程。

**验收。** 能手算累计收益与回撤；不会把夏普当胜率；能区分因子多空差收益、单多收益和相对基准收益。

## 第 16 课：IC、ICIR 与回归的研究问题

**目标与原理。** IC 是每个截面“当期分数”与“随后持有期收益”的相关系数。Rank IC 先转换成排名，再计算相关，关注相对排序。正值表示高分倾向于对应较高未来收益，负值相反；接近零可能是没有稳定排序关系，也可能是样本或噪声问题。

**例子。** 六只股票分数 1—6，对应未来收益 1%—6%，Rank IC=1；未来收益反序为 6%—1%，Rank IC=-1。这两期不能合并成“所有时候都有效”。

**操作。**

```powershell
python docs/learning/labs.py 16
```

项目 `calc_ic` 每期至少需要五只共同有效股票，否则返回 NaN。函数只对齐日期和代码，不会替你把收益移到正确持有期。输出的 ICIR 是 `IC均值/IC标准差`，当前低层函数没有自动年化。

**回归入门。** 横截面回归可以写成 `未来收益 = 截距 + b×因子值 + 控制项 + 误差`。b 描述样本中控制其他项后的线性关系，不自动等于因果效应。Fama-MacBeth 先逐期做截面回归，再汇总系数；推断需要考虑时间相关、重叠持有期和样本构造。

**练习。** 不看未来收益列，只根据分数生成权重；然后才合并未来收益做评价。比较两天 IC，计算均值为 0。解释为什么“IC>0”不保证扣除交易成本后赚钱。

**验收。** 能说明统计评价收益的起终点与回测执行是否一致；能识别 IC 的 NaN 是样本不足而非零预测能力；不会把多个重叠窗口当成独立证据简单累计。

**阶段作业。** 提交手工净值复核表、执行审计、报告解读和 IC 对齐说明。只有指标截图而没有口径说明不合格。
