# 02：数据与接口契约

[导航](README.md) · [精确签名索引](generated/INDEX.md)

契约是“输入必须满足什么、输出保证什么、失败怎样表示”。Python 标了 DataFrame，仍没说明日期在索引还是列、代码在哪、单位是什么；这些都要写清楚。

## 1. 本项目常见表格

| 名称 | 形状/关键字段 | 用途 |
| --- | --- | --- |
| 导入标准长表 | 必需 `datetime,code,name,metric,value`；可选 `remark` | Manager 导入/兼容协议，见 constants.py |
| 原始查询长表 | 常见 `datetime,code,name,metric,value,remark`；查询可有额外列 | 数据读取，具体列取决于方法 |
| 日频输入宽表 | index=行情时间，columns=证券代码，values=某指标 | 矩阵/滚动公式 |
| 因子预查询表 | `input_ts,code,因子名`，可有 `datetime,diff_hours,name` | 分组前中间表示 |
| 标签表 | MultiIndex `(input_ts,code)`，含因子列与 `因子名_label` | 组别决策 |
| 目标权重 | DatetimeIndex × 代码，通常加 `cash` | 计划配置 |
| 实际权重 | 调仓时点 × 代码/现金 | 整数手及状态处理后的实际配置 |
| 净值 nav | 日期索引 Series | 绩效指标输入 |
| 展示因子值 | 常见中文列 `信号日,股票代码,因子值,分组,目标仓位,是否触发` | 体检、择时和 Dashboard 契约 |
| 事件序列 | 时间索引 Series，值为 1 代表事件 | EventStudy 输入 |

导入端当前没有把 `unit` 作为标准六列之一；单位通常包含在指标语义/维度元数据中。研究员教学表里的额外 unit 列不能未经适配就当成实际导入契约。

## 2. 最小例子

```python
import pandas as pd

raw = pd.DataFrame({
    "input_ts": [pd.Timestamp("2024-01-04 15:00:00")] * 3,
    "code": ["A", "B", "C"],
    "score": [1., 2., 3.],
})
wide = raw.pivot(index="input_ts", columns="code", values="score")
```

长表有 3 行，宽表有 1 行 3 列。`code` 是标签，不是整数数组位置。pandas 运算会按标签对齐，代码集合不同可能产生 NaN，而不是像列表那样按顺序相乘。

`NaN` 表示缺失，不等于零；目标权重中的缺失是否补零，应由已确定的持仓规则决定。价格的缺失/零值不能照搬权重补零逻辑。

## 3. 核心接口速查

| 接口 | 输入 | 输出 | 失败/副作用 |
| --- | --- | --- | --- |
| `Datafeed(table_name, ...)` | 注册的逻辑数据集、连接参数 | 连接门面对象 | 构造时连接；close 归还资源 |
| `query_time_range(...)` | codes、起止、metric 等 | 长表 | 读库；空结果不等于连接错误 |
| `query_nearest_before/after(params)` | 时点与容差 | 匹配记录及时间相关字段 | before/after 方向不能互换 |
| `get_absolute_trade_days(begin,end,period)` | 日期、周期、exchange | Python 日期序列 | 依赖本地交易日历；非日频取周期末交易日 |
| `single_characteristic(data,metric,quantiles,...)` | 因子长表、分组字典 | 带标签 MultiIndex 表 | 严格等额组的样本不足抛 ValueError |
| `get_single_factor_weight(labeled,params)` | 标签、factor_key、mode/long/short | 权重宽表 | 可能省略从不持有的代码列 |
| `neutralize_factor(series,...,return_stats=True)` | 单截面分数与控制变量 | `(残差Series,诊断dict)` | 样本不足可能返回原序列并 skipped |
| `FactorPipeline(spec).run(start,end,...)` | 实验 spec 与运行参数 | RunResult | 查库、写图表/Excel；不是纯函数 |
| `BacktestBase(weight,symbol,amount,...)` | 权重/资金/价格与状态 | 对象上的属性 | 构造即执行；异常包含数据上下文 |
| `Analyst.from_backtest(bt,...)` | 回测对象、可选基准 | Analyst | 名称/基准可能查库 |
| `Analyst.report(...)` | 导出路径和显示选项 | 汇总及文件 | Excel/HTML 写盘，HTML 需依赖 |
| `calc_ic(factor_data,return_data,...)` | 对齐信号日的分数和未来收益宽表 | IC Series | 共同有效股票不足5返回 NaN |
| `EventStudy(feed).analyze(...)` | 事件、代码、窗口 | 含矩阵/统计的字典 | 日历和行情查询；返回内容随模式扩展 |
| `ImportJobRunner.preview(...)` | 文件/目标/模式/options | 验证、摘要、冲突和 token | 默认可查库；不应当成完全无 I/O |
| `ImportJobRunner.run(...)` | 已确认源文件和写入参数 | 任务记录字典 | 写数据库、SQLite/日志/拒绝行 |

完整参数、默认值以及内部方法见静态索引；上表是业务契约，不代替精确签名。

## 4. 时间是协议的一部分

必须区分：自然日、交易日、行情时间戳、信号可知时间、目标请求时间、实际成交时间、未来收益标签起止。

- `time_tolerance` 单位是小时；`warmup_days` 是自然日；滚动窗口常按交易日行数。
- 日频行情的开盘和收盘可有不同时间戳，宽表对齐需保留合理的日内时间语义。
- 前一交易日不等于自然日减一；`pd.bdate_range` 不能处理中国交易所节假日。
- `period_end` 与 `available_at` 不同：前者是报告期，后者是可得时间。
- 某股票从 6 月起加入指数，不意味着 3 月也能作为当时成分；PIT 过滤依赖正确生效记录。
- 交易状态读取恢复三态：1 正常、0 异常/停牌、-1 未上市或缺少正常锚点。不能把未知简单当正常。

## 5. 权重、净资产与收益

六只股票高低组多空时，股票权重和可能为 0、绝对和为 2、现金为 1；这是一种净资产记账，不能解读为没有持仓。

实际股数按 `trunc(weight×amount/price/lot_size)×lot_size` 得到。舍入后应查看 actual_weight，不用原 weight 代替真实持仓贡献。输入资金变化可能改变取整结果。

收益率用于乘法时通常是小数，如 3% 对应 0.03；数据库字段 `涨跌幅(%)` 的数值口径需另查，不能凭列名把 3 当 300% 或重复除100。

## 6. HTTP/文件边界

Python 的 Timestamp、NumPy scalar、NaN 不能原样假设为合法 JSON。serialization 负责时间和空值规范化。TS 类型同步不了中文表头或键名变动时，页面会空白或显示错误。

大表通过 Parquet 分页而非塞进单个 JSON。Parquet 出现在结果缓存，不意味着所有源文件导入接口都支持 Parquet。

RunResult 是进程内对象；RunState/结果 JSON 是 HTTP 对象；Excel 是导出文件。三者相互关联但不是同一份协议。

## 7. 接手时如何验证一个接口

记录一份五列检查卡：调用处、输入 shape/dtypes、索引语义、输出/异常、外部副作用。先用三行玩具数据或预载价格确认算术，再使用隔离的真实数据验证查询与时间。对无注解、无 docstring 的函数，直接读 return 和属性赋值，不用函数名猜返回类型。
